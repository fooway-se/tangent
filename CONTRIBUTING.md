# Contributing

Tangent is in early development and **pull requests are not being accepted yet**. The architecture and scope are still moving, and unsolicited changes are hard to merge.

What is welcome right now:

- Bug reports and feedback, through the repository's issue tracker
- Testing the installer on your own shared host and reporting what happened (PHP version, host, any error)
- Security reports; see [SECURITY.md](SECURITY.md)

If you want to try the code locally, see [docs/DEVELOPMENT.md](docs/DEVELOPMENT.md). Conventions are in [docs/ARCHITECTURE.md](docs/ARCHITECTURE.md).
